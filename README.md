### Hexlet tests and linter status:
[![Actions Status](https://github.com/AnnHaus/qa-engineer-project-85/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/AnnHaus/qa-engineer-project-85/actions)
Данный проект демонстрирует все необходимые этапы ручного тестирования open source project Codebattle.
Здесь описаны необходимые требования, тест-кейсы, результаты непосредственно тестирования, созданы баг-репорты (issues), а также проведена проверка закрытых баг-репортов на актуальность (регрессионное тестирование).
Все документы оформлены с использованием формата YAML.
Проект был создан и оформлен при поддержке школы программирования Хекслет и непосредственно специалиста по тестированию Александры Фадеевой. 
При появлении вопросов во время изучения проекта можно обращаться к автору данного проекта - Смирновой Анне Анатольевне - через электронную почту или через инструменты GitHub (issues; pull requests; discussions).
